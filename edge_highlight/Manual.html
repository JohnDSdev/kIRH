Inner Rim Highlight

Creates a separate white paint layer that fades inward from the transparent edge of the active layer.

Usage

  1. Select the layer containing your filled character/object.
  2. Choose Tools → Scripts → Inner Rim Highlight…
  3. Adjust width, opacity and softness, then click Generate.
  4. The result appears as a new paint layer above the source. Erase or mask any highlights you do not want.

Width controls how far inward the white fade extends.

Opacity controls the strongest white part of the effect.

Softness controls how gradual the fade is.

Alpha threshold ignores extremely faint source pixels; raise it if tiny stray pixels generate unwanted highlight islands.

Limit to current selection lets you generate the effect only on selected parts of the layer.

Limitations

This version supports 8-bit RGBA source layers. It uses layer transparency as the edge, so opaque internal line art does not count as a shape boundary unless it separates transparent areas.
